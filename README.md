RentEase 🏠

A tenant and rental property management web app with separate workspaces for Admins, Landlords and Tenants.

Live demo: https://renteease-zeta.vercel.app

Features
Admin
Platform overview: landlords, properties, tenants, active leases and pending invites
Recent activity stream
Add Landlord button and quick shortcuts
Menu sections for landlords, properties, tenants, invitations, activity log and settings
Landlord
Dashboard with properties, units, occupancy, tenants and leases
Rent overview: expected, collected and pending/overdue
Recent payments and maintenance requests
Add Property and Invite Tenant buttons
Menu sections for units, leases, payments, complaints and notices
Tenant
View assigned unit, monthly rent, security deposit and lease expiry
Landlord contact details and building announcements
Profile form for contact details
Menu sections for lease, payments, maintenance requests and notices
Demo Access

The login screen has a 1-click demo switcher for the Admin, Landlord and Tenant roles. The interface also includes an Email Simulator.

How to Use
Open the live demo.
Choose a role with the demo switcher.
Click Enter Workspace Console if you are still on the login screen.
Use the sidebar to explore the sections.
Hosting

Deployed on Vercel.

Project Status
